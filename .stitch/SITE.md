# HealthyTech Atlantico - Sitemap & Roadmap

## 1. Vision
A premium dashboard application to track and monitor student health, metrics, psychological status, and tests.

## 2. Sitemap
- [ ] `index` (auth/login): Authentication portal.
- [ ] `dashboard`: Main hub with KPIs and recent activity.
- [ ] `alunos`: Grid/List of all managed students.
- [ ] `aluno-detail`: Detailed 360 view of a single student (Biometrics, Questionnaires, Tests).
- [ ] `sos-alerts`: Dashboard for viewing and acting upon psychological SOS alerts.

## 3. Roadmap
- `index`
- `dashboard`
- `alunos`
- `aluno-detail`
- `sos-alerts`
